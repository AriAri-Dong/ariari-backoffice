# AriAri_Backoffice

✨ Ariari 운영진을 위한 Backoffice ✨

# 🛠️ 백오피스 관리자 시스템

이 프로젝트는 서비스 운영을 위한 **백오피스(Admin Panel)** 시스템입니다.  
사용자 관리, 공지사항, 신고/차단 관리, 통계 대시보드 기능 등을 제공합니다.

## 📦 기술 스택

### Backend

- **Java 17**
- **Spring Boot 3**
- **Gradle (Kotlin DSL or Groovy DSL)**
- JPA, Spring Security, Spring Data, etc.

### Frontend

- **Vite**
- **React 18**
- **TypeScript**
- Zustand, React Query, Chart.js, etc.

---

## 🧩 주요 기능

### ✅ 사용자 관리

- 회원 목록 조회 및 검색
- 회원 상세 조회 및 활동 이력 확인
- 회원 상태 변경 (정지, 탈퇴 등)

### 🚫 신고/차단 관리

- 신고 내역 조회 및 처리
- 차단된 사용자 목록 관리

### 📢 공지사항 관리

- 공지 등록/수정/삭제
- 팝업 여부 설정

### 📊 통계 대시보드

- 사용자 유입 추이
- 월간/일간 가입자 수
- 신고/차단 건수 통계
